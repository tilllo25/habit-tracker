# Habit Tracker

A simple web app for tracking daily habits. You add the habits you want to build, check them off each day, and see your progress over time.

## Stack

- HTML, CSS, and JavaScript (no frameworks)
- `localStorage` for saving data in the browser
- GitHub Pages for hosting

## How to run

Open `index.html` in a browser. There's no install or build step.

## Rules

- Keep everything in the three files: `index.html`, `style.css`, `app.js`.
- Ask before adding any new library.
